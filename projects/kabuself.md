# kabuself — AIが自律的に株式投資する実験基盤

> 「AIは自分で考えて株式投資ができるのか？」を、**本物のお金を一切使わずに**検証する実験システム。

仮想資金100万円で、AI（Codex）が銘柄選びから売買まで自分で行う。

ただし主役は売買そのものではなく、**「AIがなぜそう判断したのかを、必ず記録に残させる」仕組み**。

- **性格**: リアルマネー一切なし。学習・実験専用のシミュレーション

---

## 概要

人間でもAIでも、投資の失敗は「なんとなく買った」から起きる。そこでこのシステムでは、

> **AIが「なぜ買うのか」の説明文（論拠）を先に提出しないと、システムが売買を受け付けない。**

というルールをプログラムのレベルで強制している。

これにより衝動的な売買が構造的に不可能になり、あとから「あのとき何を見て、どう考えて決めたのか」を完全に振り返れる。

判断した瞬間の株価・為替・企業業績もまるごと保存されるので、AIが過去の失敗から学ぶための材料になる。

---

## 主な機能

### 株価データの取得・監視
- 日本株・米国株・為替レートを自動取得（yfinance）。データが4日以上古い場合は「情報が古すぎる」として取引を自動拒否
- 企業の業績や決算スケジュールも取得し（J-Quants）、判断の数値的な裏付けに使用
- 監視したい銘柄リストは Google Sheets（Googleの表計算）で管理して自動読み込み。接続できないときはローカルのファイルで代用

### 売買の3ステップ（この順番をシステムが強制）
1. **判断の記録（必須・最初）**: 「なぜ買うのか」の説明文、判断時点の市場データ、確信度（1〜5）を保存。有効期限は10分
2. **売買の実行**: 「判断が10分以内に作られたか」「価格データが新鮮か」「現金・保有株数は足りるか」を検証してから約定
3. **資産の更新**: 現金・保有株・損益を円建てで記録

### 資産の見える化
- 日本株（円）と米国株（ドル）を1つの画面にまとめて表示。為替レートは自動換算
- 毎日の資産推移を記録してグラフ化（同じ日に何度実行しても結果が変わらない安全設計）

### 過去の判断を検索
銘柄名やタグで過去の判断を検索できる。「同じ銘柄で以前は何を考えていたか」をAI自身が参照して、学習ループを回すための基盤。

## 技術スタック

**バックエンド（サーバー側・Python 約3,500行）**
- FastAPI（Web APIフレームワーク）+ SQLite（軽量データベース）
- yfinance（株価・為替の取得）/ J-Quants（日本株の企業情報）/ Google Sheets 連携

**フロントエンド（画面側・TypeScript）**
- Next.js + React + TypeScript（型で安全に書ける言語）
- recharts（資産推移グラフ）/ react-markdown（判断メモの表示）

**自動化**: Macの定期実行機能（launchd）で「監視リストの同期（毎日7:00）」「資産スナップショット（毎日6:00）」を自動処理

**AIのルールブック**: トレーダーAIの行動規則（1銘柄は資産の20%まで／最大10銘柄／現金5%以上は必ず残す／古い価格での取引禁止／論拠に嘘を書かない）を定義ファイルにまとめ、Claude Code に守らせている

## アーキテクチャ（構成図）

```
Claude Code（トレーダーAI）        Next.js ダッシュボード
   │ ① 判断（論拠）を記録            （閲覧専用の画面）
   │ ② 売買を実行                          │
   ▼                                       ▼
┌────────────────────────────────────────────┐
│  FastAPI バックエンド         │
│  論拠のない売買リクエストはエラーで拒否      │
└───────┬───────────┬────────────────────────┘
        ▼           ▼            ▼
   SQLite DB     yfinance     J-Quants
   （記録簿）   （株価・為替） （企業業績）
                                  │
                            Google Sheets（監視リスト）
```

**記録しているもの**: 資産 / 監視リスト / 保有株 / 判断 / 売買 / 日次スナップショット

## 技術的な見どころ

- **「判断→売買」の順番をシステムが強制**: 論拠が添えられていない売買リクエストは、エラーとして自動的に拒否する設計。AIの信頼性を「予測が当たるか」ではなく**「判断の透明性」**で担保するという思想を、コードのレベルで実現した
- **2つの通貨をまたぐ資産管理**: 日本株と米国株を1つの画面で扱い、為替レートを自動取得して円換算。元の通貨と円換算の両方を記録するので、後から検証・監査ができる
- **古い価格での取引を自動ブロック**: 市場が閉まっている時間帯や、信頼できない価格データでの売買を構造的に防止
- **どこかが失敗しても止まらない**: Google Sheets に繋がらなければローカルファイルへ切替、株価が取れなければ安全に取引拒否——部分的な故障で全体が壊れない設計
- **完全ローカル動作**: 自分のPC内だけで完結し、外部にお金も情報も出ない安全な実験環境
